# Magnus


### Install:
```txt
curl -fsSL https://raw.githubusercontent.com/yparsak/Magnus/main/scripts/install.sh -o /tmp/install.sh
sudo bash /tmp/install.sh
```
You will need to provide lichens.org API token. This will be necessary to download games from lichens.org.
If you skip this part, later you can add to Magnus/app/.env file as following:

```txt
LICHESS_TOKEN=
```
